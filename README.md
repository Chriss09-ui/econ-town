# 经世小镇

Unity 2D 小镇经营游戏项目。

## 打开项目

使用 Unity 6000.5.8f1 在 Unity Hub 中打开仓库根目录，然后打开 `Assets/Scenes/Main.unity` 并运行。

## 第三方资源

- Kenney Roguelike Modern City 素材：见 `Assets/StreamingAssets/Kenney/LICENSE_kenney.txt`（CC0）。
- Noto Sans CJK 字体：见 `Assets/ThirdPartyNotices/NotoSansCJK-OFL.txt`（SIL OFL 1.1）。
